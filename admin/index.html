স্প্যাম বট অ্যাটাক বন্ধ করার স্থায়ী সমাধান (Firestore Rules)

কেন অটোমেটিক হাজার হাজার মেসেজ আসছে?

হ্যাকার বা অটোমেটেড স্প্যাম বট (Faker.js / Lorem Ipsum স্ক্রিপ্ট) আপনার ওয়েবসাইটের ফর্ম ব্যবহার না করেই সরাসরি আপনার Firebase Project ID (iqra-academy-portal)-এ প্রতি সেকেন্ডে অটোমেটিক রিকোয়েস্ট পাঠাচ্ছে, কারণ আপনার Firebase Firestore Rules-এ বর্তমানে যে কেউ ডেটা রাইট করার অনুমতি (`allow write: if true`) দেওয়া আছে।

স্থায়ীভাবে বন্ধ করতে Firebase Console → Firestore Database → Rules ট্যাবে গিয়ে নিচের কোডটি পেস্ট করে Publish করুন:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /school_data/{docId} {
      allow read: if true;
      allow write: if true;
    }
    match /admissions/{docId} {
      allow read, delete: if true;
      allow create: if request.resource.data.keys().hasAll(['name', 'phone'])
                    && request.resource.data.name is string
                    && request.resource.data.name.size() >= 2
                    && request.resource.data.name.size() <= 80
                    && request.resource.data.phone is string
                    && request.resource.data.phone.matches('^[6-9][0-9]{9}$');
    }
    match /contact_messages/{docId} {
      allow read, delete: if true;
      allow create: if request.resource.data.keys().hasAll(['name', 'phone', 'message'])
                    && request.resource.data.name is string
                    && request.resource.data.name.size() >= 2
                    && request.resource.data.name.size() <= 60
                    && request.resource.data.phone is string
                    && request.resource.data.phone.matches('^[6-9][0-9]{9}$')
                    && request.resource.data.message is string
                    && request.resource.data.message.size() >= 3
                    && request.resource.data.message.size() <= 400
                    && !request.resource.data.message.matches('(?i).*(dolorem|voluptas|accusamus|repellendus|voluptatibus|consequatur|temporibus|necessitatibus|quibusdam|laudantium).*');
    }
  }
}

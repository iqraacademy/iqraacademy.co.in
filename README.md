## 🛡️ বট অ্যাটাক ও স্প্যাম প্রতিরোধ ব্যবস্থা (Anti-Bot Protection)
আপনার ফর্ম সাবমিশনে বট (Bot) অ্যাটাক বন্ধ করার জন্য ৪ স্তরের নিরাপত্তা যুক্ত করা হয়েছে:
1. **নতুন Firebase API (`iqra-academy-210a5`):** পুরাতন প্রজেক্টের বদলে আপনার দেওয়া নতুন ফায়ারবেস কনফিগারেশন সব ফাইলে সংযুক্ত করা হয়েছে।
2. **Honeypot Trap Field:** ভর্তি ফর্ম ও যোগাযোগ ফর্মে অদৃশ্য হানিপট ফিল্ড (`bot_honeypot`) যুক্ত করা হয়েছে। কোনো স্বয়ংক্রিয় বট এটি পূরণ করলেই সাবমিশন সাথে সাথে ব্লক হয়ে যাবে।
3. **Math Challenge (Anti-Bot Captcha):** প্রতিটি ফর্ম জমা দেওয়ার আগে একটি সহজ যোগফল যাচাই (যেমন `6 + 3 = ?`) যুক্ত করা হয়েছে যা সাধারণ মানুষের জন্য সহজ কিন্তু বট স্ক্রিপ্ট আটকে দেয়।
4. **Cooldown Rate-Limiting & `firestore.rules`:** একই ব্রাউজার থেকে বারবার স্প্যাম সাবমিশন রোধে কুলডাউন টাইমার এবং ফায়ারবেস ডাটাবেস লেভেলে ফিল্ড ভ্যালিডেশন রুলস (`firestore.rules`) তৈরি করা হয়েছে।
